# Archive

Assets that aren't used by any current page, kept here instead of deleted in
case they're useful later. Nothing in this folder is served by the live site.

- **videos-unused/** — earlier hero/card videos superseded by newer footage
  (e.g. `hero.mp4`/`hero-mobile.mp4` before the Team page hero was replaced,
  `element-v5.mp4` before the Training Programs card switched to `hero-v1`).
- **videos-raw-source/** — original uncompressed camera footage the site's
  videos were encoded from. Gitignored (100MB+ each) — present on disk only,
  not pushed to the remote. Keep these if you ever need to re-encode at a
  different quality/crop.
- **images-unused/** — photos and logo variants no longer referenced after
  a redesign (old poster-frame stills, an unused logo mark variant).
- **jpg-source-originals/** and **png-source-originals/** — the original
  .jpg/.png files each current .webp image was converted from, organized by
  their original folder (`stock/`, `poster/`, `traning/`, `poster-frames/`,
  site root). Useful if you need to re-export a `.webp` at different quality
  or dimensions later.
